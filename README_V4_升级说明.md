# 理论学习收集系统 V4：通知提取和新建活动流程修复

## 新版正确操作顺序
1. 管理员登录。
2. 点击“＋ 新建活动（先粘贴通知）”：直接进入空白草稿，不弹出预先填写主题的对话框，也不会向 Supabase 添加空活动。
3. 粘贴完整通知，点击“智能提取通知信息”。
4. 自动填入能够识别的 **月份、学习主题、学习材料标题、材料链接、截止时间（北京时间）**。界面会标明已提取与待补充字段。
5. 检查并补充会议举办日期、参与人数、学习地点等通知中没有的信息。
6. 如需开放投稿，勾选“开放为本期活动”。最后点击“保存本期设置”，此时才会写入数据库。

## 部署方法
在 `tonguu/theory-reflection` GitHub 仓库根目录**覆盖**以下三个文件：
- `app.js`
- `index.html`
- `style.css`

点击 Commit changes。GitHub Pages 发布后强制刷新（电脑 Ctrl + F5；手机关闭页面后重新打开或清理缓存）。

**不需要运行新的 SQL，不要重传或改动 config.js。**
原有报告模板 report-template.docx、ppt-background.png、历史活动及心得继续保留。

## 测试用例
通知中若出现：【9月理论学习心得征集】、学习主题：先进制造业高质量发展、学习内容：《……》微信链接、【10月18日17点前】，应分别提取 9、对应主题、材料及链接、截止时间。对于跨年或省略年份的通知，系统按当前北京时间年份填入，管理员必须核对后保存。

## 注意事项
- 新建草稿如果不点击“保存本期设置”，不会写入数据库。
- “智能提取”是基于规则的离线解析，不是 AI 大模型；不统一的通知格式仍可能需要手动修改。
- 仅从通知提取已有的信息，不会臆造学习会举办日期、参会人数和现场情况。
- 已有活动可直接选中、修改通知并重新提取；不影响过去已保存的投稿归属。
